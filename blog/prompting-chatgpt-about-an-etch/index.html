Experiment 1

Published November 21, 2026

Context- While etching small features through a mask of AZ photoresist, the features were widening, and squares were turning into circles.

Prompt 1- How would you solve this problem?

Prompt 2- How would you solve this problem given you want to optimise for least amount of fab time to solve the issue?

Prompt 3- An engineer in a research meeting, made a single suggestion that solved the problem- can you guess what that suggestion was?

Make the top 50 guesses in order of likelihood

Prompt 4- An engineer in a research meeting, made a single suggestion to tweak the way the etch is being done that solved the problem, can you guess what the suggestion was?

Make the top 50 guesses in order of likelihood

Each prompt is a separate chat, with memory off, using high mode in ChatGPT mobile app

The answer that worked in the real world, was to pulse the etch, and have cooling times periodically

Results

Prompts 1 and 2- It suggested ways to identify the root cause- which included, more metrology and testing- but did not directly blurt out a solution.

Prompt 3- The 15th guess was correct

Prompt 4- The 3rd guess was correct
